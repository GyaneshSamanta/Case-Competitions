## About

- **What:** A single repository that collects every case-competition submission Gyanesh has worked on — corporate-sponsored cases (PwC, EY, IDFC First, SBI, SUD Life, Saregama, GSK, Tata Steel), MBA-school cases (XIMB, IIM Nagpur Prodground), and the past editions of GCCH (Global Case Challenge for Healthcare).
- **Who:** Submissions are by **Gyanesh Samanta** and rotating teammates (named in the team handles inside each deck — e.g., team "Hades" for SBI IdeationX, "Buzz & Beyond" for Saregama, "Airpods" for SUD Life, "Fame-ous" for IDFC First, "Team um24348" for Prodground).
- **When:** First commit 2025-09-27, latest update 2026-03-28.
- **Where:** Submissions sent to corporate sponsors, the GCCH portfolio of past editions, and MBA-program flagships (IIM Nagpur, XIMB).
- **Why:** Case comps reward end-to-end business thinking — market sizing, financial modelling, recommendations, presentation. Keeping every submission in one place makes it easy to learn from previous decks and to share with future teammates and recruiters.

## The Story

Each top-level folder is one competition. Most contain a **paired `.pdf` + `.pptx`** submission so reviewers can read offline or screen the deck live. A few stand out:

- **GCCH Past Editions** — a small library of *winning* and notable past submissions (Auburn Tigers 2023, University of Toronto's Gravity Defiers, the Harvard "BostonEquiTeaParty" case, and an NVDA / AMD M&A pitch from team Kicking Assets) — kept for reference rather than as personal submissions.
- **EY Techathon** and **Prodalytics** — include the original problem-statement PDFs alongside the work.
- **SBI IdeationX 2025 (team Hades)** — ships both the deck and the recorded video pitch (`XIMB_Hades.mp4`).
- **PWC Consultant Final Placements** — includes the consulting-style "Case Unboxed" submission used for final-round placements.

Across all of them the recurring themes are market-entry strategy, product / feature prioritization, financial projection (ROI, cost optimization, revenue forecasting), and social-impact framing. The decks are intentionally kept in their as-submitted form — typos, branding, and all — so the archive doubles as a track record.

## Getting Started

This is a documentation repo — no code to run.

```bash
# 1. Clone
git clone https://github.com/GyaneshSamanta/Case-Competitions.git
cd Case-Competitions

# 2. Browse a competition folder and open the deck
open "PWC Consultant Final Placements/PWC Case Unboxed - Gyanesh.pdf"
```
